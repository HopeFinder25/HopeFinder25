# Missing Persons Alerts Nationwide

A volunteer-run community alert network sharing verified missing-person alerts from across the U.S. — neighbors helping bring people home.

- 🌐 **Website:** https://missingpersonsalerts.github.io/missing-persons-alerts/
- 🛫 **Live Flight Board:** https://missingpersonsalerts.github.io/missing-persons-flight-board/ — every active case, one screen, with photos and tap-to-call numbers

**Follow the alerts**
- Instagram: https://www.instagram.com/missing.person.usa
- TikTok: https://www.tiktok.com/@missingpersonsalertsus
- YouTube: https://www.youtube.com/@missingpersonalerts
